# Mirror

Keep past Codex conversations beside your work in native macOS reference windows.

[完整中文文档](README.md) · [Download complete preview](https://github.com/ChanghaoLiao/Mirror/releases/tag/v1.0.0-preview.1)

The complete archive contains Mirror.app, companion skills and function tools. The small toolkit downloads the fixed desktop archive from the same release when needed. No source build or model API key is required.

Apple Silicon/macOS14+ required. Desktop1.0.0 build10; distribution1.0.0-preview.1. Ad-hoc signed and NOT Apple notarized. The user must complete macOS first-open approval and optional Accessibility authorization. Never remove quarantine or disable Gatekeeper.

Mirror operations run deterministic local code. The host Agent's reasoning and tool context can still consume tokens. A Mac-side executor is required; cloud-only ChatGPT cannot control local windows. History remains Codex-only, regardless of controlling Agent.
