# 安全问题 / Security

当前维护公开预览版 `0.2.1`，没有其他受支持的公开版本。

可能泄露对话、突破只读限制、自动读取未选择的附件或执行不可信输入的问题，请通过仓库 **Security → Report a vulnerability** 私下报告：

[私密安全报告](https://github.com/ChanghaoLiao/Mirror/security/advisories/new)

请说明版本、系统、影响及最小复现步骤，尽量使用虚构数据。不要包含 Token、真实对话、账号信息或完整状态文件。普通使用问题请提交脱敏的公开 Issue。

这是个人维护的项目，暂不承诺固定响应时限。临时签名和未公证属于当前分发限制，见[安装说明](docs/installation.md)。

## English

The supported public version is preview `0.2.1`. Privately report conversation disclosure, read-only boundary violations, unselected attachment access or execution of untrusted input through **Security → Report a vulnerability**, using the link above.

Include version, OS, impact and minimal reproduction with synthetic data. Do not include credentials, real conversations, account information or full state. Ordinary bugs belong in a redacted public issue. This is an individually maintained project with no guaranteed response time. Ad-hoc signing and lack of notarization are documented distribution limitations.
