# 常见问题

[English](troubleshooting.en.md) · [返回首页](../README.md)

| 现象 | 先做什么 |
| --- | --- |
| 下载后无法打开 | 先读[安装说明](installation.md)的未公证说明，核验来源和校验和；不要关闭全局系统保护 |
| 没有Dock图标 | Mirror在菜单栏，寻找 **◧** |
| 未找到Codex | “选择Codex…”需要实际可执行文件，不是聊天窗口；见[路径示例](installation.md#选择-codex) |
| 已有权限但显示未绑定 | 权限与窗口选择不同；先点击目标Codex，再选择“绑定Codex窗口” |
| 系统里已开启，Mirror仍显示未授权 | 退出Mirror，确认你打开的是同一位置的新版本；核对系统列表中的Mirror应用位置，返回引导“重新检查” |
| 窗口随宿主消失 | 跟随会根据当前工作组和宿主状态隐藏；返回宿主或从◧打开/恢复参考 |
| 会话不在列表里 | 列表是当前Codex本地索引，使用同一个本机安装；搜索标题、加载更多；网页版云端对话不是本地历史 |
| 刷新失败 | 旧内容会保留。临时断连/超时自动重试最多三次；45秒结束后核对CLI路径，必要时刷新一次 |
| 格式错误或请求拒绝 | 自动重试不能修复兼容性问题；记录Mirror/CLI版本与错误类型，提交脱敏Issue |
| 所选文字无法定位 | 辅助功能没有提供选区或匹配不唯一；改为手动选择会话、正文查找 |
| 图片只有占位 | 点击“选择图片预览”并明确选择文件，Mirror不自动打开附件路径 |
| 更新后权限失效 | 临时签名变化可能要求重新授权；保持固定位置，核对系统中对应的Mirror条目 |

请不要直接删除不认识的应用或授权条目。多个Mirror条目时，先核实路径，再只处理对应的旧应用授权；无需删除源代码、安装包或Codex历史。

如果某条会话在新版本仍持续读取失败，反馈：Mirror版本、macOS版本、CodexCLI版本、初次读取还是刷新、错误提示及复现步骤。不要贴正文或真实会话ID。暂时可保留已读内容，并用Codex主窗口继续工作。
