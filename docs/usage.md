# 使用指南

[English](usage.en.md) · [返回首页](../README.md)

## 三个概念

**会话**是 Codex 已有的一段对话；**参考窗口**是对它的一次独立阅读；**绑定**是让一组参考窗口跟随某个具体 Codex 窗口。复制参考窗口不会复制会话，更不会让 AI 再回答一次。

未绑定时，你仍可以从 Mirror 菜单打开窗口并选择会话。授权辅助功能后，先点击目标 Codex 窗口，再选择“绑定 Codex 窗口”。窗口标题变了、重启后同名窗口无法唯一识别时，需要重新绑定。

## 完整工作流程

1. **◧ → 打开参考窗口**或 **⇧⌘M**。
2. 点击“切换会话”，搜索标题，选择一条。列表有下一页时点击“加载更多会话”。宿主标题只有唯一精确匹配时才会尝试自动选择；不要依赖“最近更新的会话”推断当前会话。
3. 滚到要保留的位置，按 **⌘D**。新窗口从当前阅读位置开始，之后独立滚动、调整字号或换会话。
4. 用标题栏移动、窗口边缘调整大小。重启后恢复窗口大小、位置、字号和文字锚点；不会保存正文。
5. 阅读最新回答时按 **⌘R**，或从 ••• 选择“刷新对话”。已有内容保持可读；完整成功后替换，保留刷新期间你正在读的位置。

第一次读取没有旧内容时会逐步显示，尚未读完会明确提示。失败或取消可能留下不完整的初次结果；再次刷新即可重试。已经完整读过的内容在更新失败/取消后保留。临时断连/超时自动恢复，格式错误或拒绝会明确显示；不需要连点刷新。

## 查找、复制与图片

**⌘F**查找已加载的正文，Return或“下一个”移动到下一处，“清除”回到查找前的位置。搜索不修改源内容。会话选择的搜索只查标题，和正文查找是两个入口。

选中文字后 **⌘C**。••• →“复制当前完整消息”复制当前选中/阅读到的消息及原始 Markdown，而非整个会话。代码和表格有自己的横向滚动区域。图片默认占位；“选择图片预览”只读取你在系统文件选择器中选择的图片，不自动打开对话中的路径。

## 所有菜单入口

| 菜单 | 功能 |
| --- | --- |
| 顶部“切换会话” | 标题搜索、列表选择、加载更多 |
| 顶部“查找” | 正文搜索、下一个、清除 |
| ••• | 复制参考、刷新、复制完整消息、字号增减、隐藏、外观与语言、设置与权限、关闭、返回阅读 |
| 菜单栏 ◧ | 打开参考、从所选文字打开、恢复隐藏参考、绑定窗口、设置与权限、选择 Codex、外观与语言、关于、退出 |

Escape关闭覆盖面板并恢复触发按钮的键盘焦点，点击面板外侧也可关闭。字号范围11–26，仅当前参考生效。外观和界面语言全局生效；语言设置不翻译对话。

**隐藏**保留窗口和位置，**◧ → 恢复隐藏的参考窗口**恢复当前组；**关闭（⌘W）**仅结束这个参考，兄弟窗口继续存在。退出应用后，由本地状态恢复仍保留的参考。

## 窗口跟随与所选文字

绑定后，窗口组会根据宿主的焦点、最小化等状态调整可见性；点击本组参考窗口仍保持可见。没有权限或没有绑定时，这种自动跟随不可用。部分全屏/Spaces行为仍需进一步验证。

“从所选文字打开”尽力读取宿主辅助功能的选中文字，再在关联会话中定位；选区缺失或不能唯一匹配会提示。它不是“当前屏幕可见消息”接口。

开发者可使用明确ID的只读深链：

```sh
open 'mirror://open?conversation=THREAD_ID&message=TURN_ID%2FITEM_ID'
```

替换为 provider 返回并正确进行URL编码的ID；message可省略。链接不会发送消息、启动或复制Agent任务。不要公开真实深链，它可能透露会话标识。
