# 隐私与本地数据

[English](privacy.en.md) · [返回首页](../README.md)

Mirror 不实现遥测、上传服务、内置账号或模型调用。它启动本机 Codex App Server，关闭该服务的 analytics，并只允许初始化、列出和读取历史。Codex 自己的账号、配置、磁盘历史和网络行为由 Codex 管理；这不是对 Codex 全部行为的承诺。

## Mirror 保存什么

对话正文在内存中，由同源窗口共享，不由 Mirror 缓存到磁盘。非活动快照最多8项、32MiB源文本字节；活动内容不计入该预算。这个数字不是整个进程内存上限。

`~/Library/Application Support/Mirror/state.json` 保存窗口位置/大小、字号、会话ID、消息/字符阅读锚点、工作组及宿主标题等元数据。它仍可能透露你打开过哪些会话，**不要把原文件上传到Issue**。文件原子写入，权限为0600；损坏或不支持的状态文件会保留，并停止本次写入。

外观和语言、选择的Codex位置及首次引导标记保存在 macOS UserDefaults 中。图片预览仅在当前参考的内存中保留，不保存预览副本。关闭窗口释放不再需要的数据。

## 权限和附件

辅助功能可让 Mirror 读取宿主窗口身份、标题和尽力读取选中文字，用于绑定、显示/隐藏及定位。用户亲自授权；没有权限仍能手动阅读。

不自动探测正文中的本地路径，不自动加载附件，不获取远程图片。普通阅读不需要屏幕录制或完整磁盘访问。打开用户点击的网页链接由系统处理。

## 反馈和清理

反馈使用虚构内容或充分打码的截图；检查窗口标题、选中内容、菜单、文件路径和桌面背景。不要附账号、密钥、真实深链或Codex原始历史。

退出 Mirror 后删除上面的 `state.json` 可重置窗口，删除 Mirror 应用可卸载；两者都不会删除 Codex 对话。首次引导标记和外观偏好可能仍在UserDefaults中。安全问题请按[安全说明](../SECURITY.md)私下报告。
